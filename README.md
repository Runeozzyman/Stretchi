# Stretchi
Mobile app powered by a vertical agent for pain relief instruction.

## Exercise data

Exercise names, instructions, target muscles, and equipment come from the public [wger](https://wger.de) exercise catalog (`https://wger.de/api/v2/exerciseinfo/`). That catalog is licensed under [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). wger and the per-exercise `license_author` must stay credited, and adaptations of this catalog must stay under the same license. Images and non-English translations are not imported.
